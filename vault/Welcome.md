# Welcome to your vault

This is a clean, general-purpose Obsidian starter with a custom theme, a note
banner, ready-made templates, and a live dashboard. Everything here is yours to
change — rename folders, delete these example notes, and make it your own.

> [!tip] First steps
> 1. Open [[Dashboard]] — it lists recent notes and what needs attention.
> 2. Make a note: `Ctrl/Cmd + P` ▸ **Templater: Open Insert Template modal** ▸ **General note**.
> 3. Drop notes anywhere. The `Notes/` folder is just a starting point.

## What's included

> [!info]+ The pieces
> - **Theme** — a Rosé Pine editorial look (light *Dawn* / dark *Moon*). Switch it in *Settings ▸ Appearance ▸ Themes*.
> - **Note banner** — the "active context" card at the top of each note updates automatically when you move or rename the note.
> - **Templates** — a flexible *General note* template plus a *Default* one that every new note picks up automatically.
> - **Dashboard** — recent notes, a focus panel, and simple upkeep stats.
> - **Maintenance scripts** — optional Python helpers in `00Meta/Scripts`.

## Make it yours

- Delete this note and `Notes/Example Note` whenever you like.
- Create top-level folders for however *you* think (projects, areas, journals — anything).
- Adjust the theme via *Settings ▸ Style Settings* once that plugin is installed.

Happy note-taking.
